# المترجم الفوري

يسمع الصوت (ميكروفون الجوال أو صوت الجوال الداخلي)، يحوّله لنص (Vosk)، يترجمه للعربية (ML Kit)،
ويعرضه على التلفاز عبر تطبيق VI Translator للتلفاز (نفس طريقة الربط بالكود المكوّن من 6 أرقام).

## البناء
- **Android Studio:** افتح المجلد، انتظر Sync، ثم Build > Build APK(s).
- **GitHub Actions:** ارفع المجلد لمستودع، شغّل Build APK من تبويب Actions، ونزّل الـ APK من Artifacts.

## الملفات
- `TvLink.kt`: البحث عن التلفاز وربطه بالكود
- `TvServer.kt`: صفحة الترجمة التي يعرضها التلفاز (الخطوط والألوان والحجم)
- `TranslateService.kt`: الصوت ← نص ← ترجمة
- `MainActivity.kt`: الشاشة والإعدادات
- `Langs.kt`: لغات الصوت

## الترخيص
مبني على أجزاء من VI Translator (ربط التلفاز وصفحة العرض والخطوط)، وهو مرخّص AGPL-3.0، فهذا المشروع كذلك (ملف LICENSE).
